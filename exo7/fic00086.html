Correction de l'exercice 1

  1. D'après la formule du binôme de NEWTON, $$\forall n \in \mathbb{N}, \sum_{k=0}^n \binom{n}{k} = (1+1)^n = 2^n$$
  2. Soit $n \in \mathbb{N}^*$. Posons $S_1 = \sum_{k \text{ pair}} \binom{n}{k}$ et $S_2 = \sum_{k \text{ impair}} \binom{n}{k}$. $S_1 - S_2 = \sum_{k=0}^n (-1)^k \binom{n}{k} = (1-1)^n = 0$ (car $n \geq 1$). Donc $S_1 = S_2$. $S_1 + S_2 = \sum_{k=0}^n \binom{n}{k} = 2^n$. Donc $S_1 = S_2 = 2^{n-1}$. $$\forall n \in \mathbb{N}^*, \binom{n}{0} + \binom{n}{2} + \binom{n}{4} + \dots = \binom{n}{1} + \binom{n}{3} + \binom{n}{5} + \dots = 2^{n-1}$$
  3. En posant $j = e^{2i\pi/3}$, on a : $$\sum_{k=0}^n \binom{n}{k} = (1+1)^n = 2^n, \quad \sum_{k=0}^n \binom{n}{k} j^k = (1+j)^n \quad \text{et} \quad \sum_{k=0}^n \binom{n}{k} j^{2k} = (1+j^2)^n$$ En additionnant ces trois égalités, on obtient $$\sum_{k=0}^n \binom{n}{k} (1 + j^k + j^{2k}) = 2^n + (1+j)^n + (1+j^2)^n$$ On rappelle que $1+j^k+j^{2k} = 3$ si $k$ est un multiple de 3, et $0$ sinon. Finalement, $$\sum_{k=0}^n \binom{n}{k} (1 + j^k + j^{2k}) = 3\sum_{k=0}^{E(n/3)} \binom{n}{3k}$$ D'où $$\sum_{k=0}^{E(n/3)} \binom{n}{3k} = \frac{1}{3} \left(2^n + 2\operatorname{Re}((1+j)^n)\right)$$ Comme $1+j = -j^2 = e^{-i\pi/3} e^{i2\pi/3} = e^{i\pi/3}$, $$\sum_{k=0}^{E(n/3)} \binom{n}{3k} = \frac{1}{3} \left(2^n + 2\cos\left(\frac{n\pi}{3}\right)\right)$$ Les sommes pour $\binom{n}{3k+1}$ et $\binom{n}{3k+2}$ sont trouvées de manière similaire en multipliant par $j^2$ ou $j$ avant sommation.
  4. Pour $1 \leq k \leq n$: $$k \binom{n}{k} = k \frac{n!}{k!(n-k)!} = \frac{n!}{(k-1)!(n-k)!} = n \frac{(n-1)!}{(k-1)!((n-1)-(k-1))!} = n \binom{n-1}{k-1}$$
  5. $\binom{2n}{n}$ est le coefficient de $x^n$ dans le développement de $(1+x)^{2n}$. D'autre part, $(1+x)^{2n} = (1+x)^n (1+x)^n = \left(\sum_{k=0}^n \binom{n}{k} x^k\right) \left(\sum_{j=0}^n \binom{n}{j} x^j\right)$. Le coefficient de $x^n$ dans le produit est $\sum_{k=0}^n \binom{n}{k} \binom{n}{n-k}$. Puisque $\binom{n}{n-k} = \binom{n}{k}$, le coefficient de $x^n$ est $\sum_{k=0}^n \binom{n}{k}^2$. Par identification des coefficients : $$\binom{2n}{n} = \sum_{k=0}^n \binom{n}{k}^2$$
  6. * 1ère somme: $\sum_{k=0}^n k \binom{n}{k}$. Utilisons $k \binom{n}{k} = n \binom{n-1}{k-1}$: $$\sum_{k=0}^n k \binom{n}{k} = \sum_{k=1}^n n \binom{n-1}{k-1} = n \sum_{j=0}^{n-1} \binom{n-1}{j} = n 2^{n-1}$$ * 2ème somme: $\sum_{k=0}^n \frac{1}{k+1} \binom{n}{k}$. Utilisons $\frac{1}{k+1} \binom{n}{k} = \frac{1}{n+1} \binom{n+1}{k+1}$. $$\sum_{k=0}^n \frac{1}{k+1} \binom{n}{k} = \sum_{k=0}^n \frac{1}{n+1} \binom{n+1}{k+1} = \frac{1}{n+1} \sum_{j=1}^{n+1} \binom{n+1}{j}$$ $$\frac{1}{n+1} (2^{n+1} - \binom{n+1}{0}) = \frac{2^{n+1}-1}{n+1}$$
  7. Pour $1 \leq k \leq n-p$: $\binom{p+k}{p} = \binom{p+k+1}{p+1} - \binom{p+k}{p+1}$. Sommation télescopique : $$\sum_{k=0}^{n-p} \binom{p+k}{p} = \binom{n+1}{p+1}$$ Interprétation dans le triangle de PASCAL (Formule du hockey ou de la crosse) : la somme des coefficients le long d'une colonne (diagonale peu pentue) est égale au coefficient situé sur la ligne suivante et dans la colonne d'après.
  8. (a) $I_n = \int_0^1 (1 - x^2)^n dx$. $I_n - I_{n+1} = \int_0^1 (1 - x^2)^n - (1 - x^2)^{n+1} dx = \int_0^1 (1 - x^2)^n x^2 dx$. Intégration par parties sur $I_n - I_{n+1}$: Posons $u = x$ et $v' = x(1-x^2)^n$. $v = -\frac{1}{2(n+1)}(1-x^2)^{n+1}$. $$I_n - I_{n+1} = \left[x v\right]_0^1 - \int_0^1 v dx = 0 - \int_0^1 \left(-\frac{1}{2(n+1)}(1-x^2)^{n+1}\right) dx = \frac{1}{2(n+1)} I_{n+1}$$ D'où $I_n = I_{n+1} + \frac{1}{2(n+1)} I_{n+1} = \frac{2n+3}{2n+2} I_{n+1}$. Relation de récurrence : $$(2n+3)I_{n+1} = 2(n+1)I_n$$ $I_0 = 1$. Par récurrence, on trouve : $$I_n = \frac{2n}{2n+1} \frac{2n-2}{2n-1} \dots \frac{2}{3} I_0 = \frac{(2n)!!}{(2n+1)!!}$$ (b) L'identité est $I_n = \sum_{k=0}^n (-1)^k \binom{n}{k} \frac{1}{2k+1}$. L'égalité est : $$\sum_{k=0}^n (-1)^k \binom{n}{k} \frac{1}{2k+1} = \frac{2 \cdot 4 \dots (2n)}{1 \cdot 3 \dots (2n+1)}$$ On a $I_n = \int_0^1 (1 - x^2)^n dx = \int_0^1 \sum_{k=0}^n \binom{n}{k} (-1)^k x^{2k} dx$. $$I_n = \sum_{k=0}^n (-1)^k \binom{n}{k} \int_0^1 x^{2k} dx = \sum_{k=0}^n (-1)^k \binom{n}{k} \left[\frac{x^{2k+1}}{2k+1}\right]_0^1$$ $$I_n = \sum_{k=0}^n (-1)^k \binom{n}{k} \frac{1}{2k+1}$$ L'identité est démontrée en comparant avec le résultat du (a).

Correction de l'exercice 4

Soit $u_k = \binom{n}{k} a^k b^{n-k}$ le terme général du développement de $(a+b)^n$, pour $0 \leq k \leq n$.

Pour $0 \leq k \leq n-1$, le rapport des termes consécutifs est : $$\frac{u_{k+1}}{u_k} = \frac{\binom{n}{k+1} a^{k+1} b^{n-k-1}}{\binom{n}{k} a^k b^{n-k}} = \frac{n-k}{k+1} \frac{a}{b}$$

Le terme $u_{k+1}$ est plus grand que $u_k$ si $\frac{u_{k+1}}{u_k} > 1$, c'est-à-dire : $$\frac{n-k}{k+1} \frac{a}{b} > 1 \Leftrightarrow (n-k)a > (k+1)b \Leftrightarrow ka + k b < na - b$$ $$\Leftrightarrow k < \frac{na-b}{a+b}$$

Posons $K = \frac{na-b}{a+b}$.

  • Si $K < 0$ (i.e., $na \leq b$): la suite $(u_k)$ est strictement décroissante. Le plus grand terme est $u_0 = b^n$.
  • Si $K \geq n-1$ (i.e., $na-b \geq (n-1)(a+b) = na+nb-a-b \Leftrightarrow a \geq nb$): la suite $(u_k)$ est strictement croissante. Le plus grand terme est $u_n = a^n$.
  • Si $0 \leq K < n-1$:
    • Si $K \notin \mathbb{N}$, posons $k = E(K) + 1$. La suite $(u_k)$ croît strictement jusqu'à l'indice $k$ puis décroît strictement. Le plus grand terme est $u_k$.
    • Si $K \in \mathbb{N}$, posons $k = K$. Le plus grand terme est atteint deux fois, aux indices $k$ et $k+1$. $u_k = u_{k+1}$.
