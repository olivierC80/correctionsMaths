Corrigé du TD 04 : Sommes et produits

Autocorrection A

On considère deux suites \((a_n)_{n\ge 0}\) et \((S_n)_{n\ge 0}\) reliées par la relation \(\forall n \ge 0, S_n = \sum_{k=0}^n a_k\).
  1. Déterminer \(a_n\) en fonction des valeurs de la suite \((S_n)_{n\ge 0}\).
  2. Exprimer à l'aide des valeurs de la suite \((S_n)_{n\ge 0}\) les sommes suivantes.

Corrigé

  1. C'est un principe de base pour passer d'une série à la suite de ses termes. Pour \(n \ge 1\), on a \(S_n = a_0 + a_1 + \dots + a_{n-1} + a_n = S_{n-1} + a_n\). On en déduit que : \[ \forall n \ge 1, \quad a_n = S_n - S_{n-1} \] Pour \(n=0\), la relation donne \(S_0 = \sum_{k=0}^0 a_k = a_0\). En résumé : \(a_0 = S_0\) et \(a_n = S_n - S_{n-1}\) pour \(n \ge 1\).
    1. \(\sum_{k=0}^{n+1} a_k = S_{n+1}\) (par définition).
    2. \(\sum_{k=n+1}^{2n} a_k = \left(\sum_{k=0}^{2n} a_k\right) - \left(\sum_{k=0}^{n} a_k\right) = S_{2n} - S_n\) (Relation de Chasles pour les sommes).
    3. \(\sum_{k=0}^n 2a_k = 2 \sum_{k=0}^n a_k = 2S_n\) (par linéarité de la somme).
    4. \(\sum_{k=0}^n (a_k - 1) = \left(\sum_{k=0}^n a_k\right) - \left(\sum_{k=0}^n 1\right) = S_n - (n+1)\) (attention, il y a \(n+1\) termes dans la somme).
    5. \(\sum_{k=0}^n (a_k - k) = \left(\sum_{k=0}^n a_k\right) - \left(\sum_{k=0}^n k\right) = S_n - \frac{n(n+1)}{2}\) (en utilisant la somme des premiers entiers).

Exercice 1

Soit \(n \in \mathbb{N}\). Calculer les sommes suivantes.

Corrigé

  1. \(\sum_{k=0}^n (-1)^k\). C'est une somme géométrique de raison \(-1\). Si \(n\) est pair, on a un nombre impair de termes (\(n+1\)), la somme est \(1-1+1-1+\dots+1 = 1\). Si \(n\) est impair, on a un nombre pair de termes, la somme est \(1-1+1-1+\dots-1 = 0\). On peut écrire : \(\sum_{k=0}^n (-1)^k = \frac{1+(-1)^n}{2}\).
  2. \(\sum_{k=2}^{n+1} k = \left(\sum_{k=1}^{n+1} k\right) - 1 = \frac{(n+1)(n+2)}{2} - 1 = \frac{n^2+3n+2-2}{2} = \frac{n(n+3)}{2}\).
  3. \(\sum_{k=1}^n 2k = 2 \sum_{k=1}^n k = 2 \frac{n(n+1)}{2} = n(n+1)\).
  4. \(\sum_{k=n+1}^{2n} 2k = 2 \sum_{k=n+1}^{2n} k = 2 \left( \sum_{k=1}^{2n} k - \sum_{k=1}^n k \right) = 2 \left( \frac{2n(2n+1)}{2} - \frac{n(n+1)}{2} \right) = n(2n+1) - n(n+1) = n(2n+1-n-1) = n(n) = n^2\). Un instant, il y a une erreur de calcul. Reprenons : \(2n(2n+1) - n(n+1) = 4n^2+2n - n^2-n = 3n^2+n = n(3n+1)\). Voilà.
  5. \(\sum_{k=0}^n 2^k\). Somme géométrique de raison 2. \(\frac{2^{n+1}-1}{2-1} = 2^{n+1}-1\).
  6. \(\sum_{k=n+1}^{2n} 2^k = \left(\sum_{k=0}^{2n} 2^k\right) - \left(\sum_{k=0}^n 2^k\right) = (2^{2n+1}-1) - (2^{n+1}-1) = 2^{2n+1} - 2^{n+1} = 2^{n+1}(2^n-1)\).
  7. \(\sum_{k=0}^{2n} (-1)^k k = (0-1) + (2-3) + (4-5) + \dots + ((2n-2)-(2n-1)) + 2n\). On a \(n\) paires de la forme \((2j - (2j+1)) = -1\). La somme est donc \(n \times (-1) + 2n = -n+2n = n\).
  8. \(\sum_{k=0}^n (-1)^{n-k}\). On effectue le changement d'indice \(j=n-k\). Quand \(k=0, j=n\). Quand \(k=n, j=0\). La somme devient \(\sum_{j=0}^n (-1)^j\), qui est la somme de la question (i). La valeur est donc \(\frac{1+(-1)^n}{2}\).

Exercice 4

Utiliser la somme télescopique \((n+1)^4 = \sum_{k=0}^n \left[ (k+1)^4 - k^4 \right]\) pour obtenir une formule pour \(\sum_{k=0}^n k^3\).

Corrigé

C'est une méthode classique et puissante pour trouver les formules des sommes de puissances. 1. On part de l'identité télescopique : \[ \sum_{k=0}^n \left( (k+1)^4 - k^4 \right) = (n+1)^4 - 0^4 = (n+1)^4 \] 2. On développe le terme général de la somme en utilisant la formule du binôme de Newton : \[ (k+1)^4 - k^4 = (k^4 + 4k^3 + 6k^2 + 4k + 1) - k^4 = 4k^3 + 6k^2 + 4k + 1 \] 3. On réinjecte ce développement dans la somme et on utilise la linéarité : \[ \sum_{k=0}^n (4k^3 + 6k^2 + 4k + 1) = (n+1)^4 \] \[ 4\sum_{k=0}^n k^3 + 6\sum_{k=0}^n k^2 + 4\sum_{k=0}^n k + \sum_{k=0}^n 1 = (n+1)^4 \] 4. On isole la somme que l'on cherche, \(\sum k^3\) (notons-la \(S_3(n)\)) : \[ 4S_3(n) = (n+1)^4 - 6\sum_{k=0}^n k^2 - 4\sum_{k=0}^n k - \sum_{k=0}^n 1 \] 5. On utilise les formules connues pour les sommes de puissances inférieures : \(\sum_{k=0}^n k^2 = \frac{n(n+1)(2n+1)}{6}\), \(\sum_{k=0}^n k = \frac{n(n+1)}{2}\) et \(\sum_{k=0}^n 1 = n+1\). \[ 4S_3(n) = (n+1)^4 - 6\frac{n(n+1)(2n+1)}{6} - 4\frac{n(n+1)}{2} - (n+1) \] \[ 4S_3(n) = (n+1)^4 - n(n+1)(2n+1) - 2n(n+1) - (n+1) \] Factorisons par \((n+1)\) pour simplifier les calculs : \[ 4S_3(n) = (n+1) \left[ (n+1)^3 - n(2n+1) - 2n - 1 \right] \] \[ 4S_3(n) = (n+1) \left[ (n^3 + 3n^2 + 3n + 1) - (2n^2+n) - 2n - 1 \right] \] \[ 4S_3(n) = (n+1) \left[ n^3 + (3-2)n^2 + (3-1-2)n + (1-1) \right] \] \[ 4S_3(n) = (n+1) [ n^3 + n^2 ] = (n+1)n^2(n+1) = n^2(n+1)^2 \] 6. On conclut : \[ \sum_{k=0}^n k^3 = \frac{n^2(n+1)^2}{4} = \left( \frac{n(n+1)}{2} \right)^2 \]

Cette méthode permet de trouver une formule pour \(\sum k^p\) à condition de connaître celles pour \(\sum k^j\) avec \(j < p\).

Autocorrection B

Soit \(n \in \mathbb{N}\). Calculer les sommes suivantes.

Corrigé

Ces sommes se calculent très efficacement à l'aide de la formule du binôme de Newton : \((a+b)^n = \sum_{k=0}^n \binom{n}{k} a^k b^{n-k}\).

  • \(\sum_{k=0}^n (-1)^k \binom{n}{k}\)

    On reconnaît le développement de \((a+b)^n\) avec \(a=-1\) et \(b=1\). \[ \sum_{k=0}^n \binom{n}{k} (-1)^k (1)^{n-k} = (-1+1)^n = 0^n \] Attention au cas \(n=0\). Si \(n \ge 1\), la somme vaut 0. Si \(n=0\), la somme est \(\sum_{k=0}^0 (-1)^k \binom{0}{k} = (-1)^0 \binom{0}{0} = 1\). Ce qui est cohérent car \(0^0=1\).

  • \(\sum_{k=0} (-1)^k \binom{n}{2k}\) (la somme va jusqu'à \(\lfloor n/2 \rfloor\))

    C'est une somme sur les indices pairs. L'astuce classique est de considérer \((1+x)^n\) et \((1-x)^n\) ou d'utiliser les nombres complexes. Considérons le développement de \((1+i)^n\) : \[ (1+i)^n = \sum_{j=0}^n \binom{n}{j} i^j \] La partie réelle de cette expression est obtenue pour les puissances paires de \(i\). Rappelons que \(i^{2k} = (i^2)^k = (-1)^k\). \[ \text{Re}((1+i)^n) = \text{Re} \left( \sum_{j=0}^n \binom{n}{j} i^j \right) = \sum_{k=0}^{\lfloor n/2 \rfloor} \binom{n}{2k} \text{Re}(i^{2k}) = \sum_{k=0}^{\lfloor n/2 \rfloor} \binom{n}{2k} (-1)^k \] Il nous suffit donc de calculer la partie réelle de \((1+i)^n\). On passe en forme polaire/exponentielle : \(1+i = \sqrt{2} e^{i\pi/4}\). Donc, \((1+i)^n = (\sqrt{2})^n e^{in\pi/4} = 2^{n/2} \left( \cos\left(\frac{n\pi}{4}\right) + i \sin\left(\frac{n\pi}{4}\right) \right)\). La partie réelle est \(2^{n/2} \cos\left(\frac{n\pi}{4}\right)\). La somme vaut donc \(\mathbf{2^{n/2} \cos(n\pi/4)}\).

  • \(\sum_{k=0}^n 2^{2k} \binom{n}{k}\)

    On réécrit la somme pour faire apparaître la structure du binôme : \[ \sum_{k=0}^n 2^{2k} \binom{n}{k} = \sum_{k=0}^n (2^2)^k \binom{n}{k} = \sum_{k=0}^n \binom{n}{k} 4^k 1^{n-k} \] On reconnaît le développement de \((4+1)^n\). La somme vaut donc \((4+1)^n = \mathbf{5^n}\).
