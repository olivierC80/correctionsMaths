Correction de l'exercice 1

Soient $x$ et $y$ deux réels tels que $0 < x \leq y$.

  1. $m = \frac{x+y}{2}$. $x \leq \frac{x+y}{2} \leq y$ est équivalent à $2x \leq x+y \leq 2y$, soit $x \leq y$. Vrai. $$x \leq m \leq y$$
  2. $g = \sqrt{xy}$. $x \leq \sqrt{xy} \leq y$ est équivalent à $x^2 \leq xy \leq y^2$. Vrai car $x, y > 0$ et $x \leq y$. $$x \leq g \leq y$$
  3. $m \geq g$. $$\frac{x+y}{2} - \sqrt{xy} = \frac{1}{2}(x - 2\sqrt{xy} + y) = \frac{1}{2}(\sqrt{y} - \sqrt{x})^2 \geq 0$$ $$g \leq m$$
  4. $h = \frac{2}{\frac{1}{x} + \frac{1}{y}}$. Par définition, $h$ est la moyenne harmonique de $x$ et $y$. $\frac{1}{y} \leq \frac{1}{m} \leq \frac{1}{x}$ (d'après 1), appliquée à $\frac{1}{y}$ et $\frac{1}{x}$) $\frac{1}{m} = \frac{2}{x+y}$ et $\frac{1}{h} = \frac{1}{2}\left(\frac{1}{x} + \frac{1}{y}\right)$. $\frac{1}{h} \geq \frac{1}{m}$ (d'après 3), appliquée à $\frac{1}{x}$ et $\frac{1}{y}$), soit $h \leq m$.
  5. $h \leq g$. $g$ est la moyenne géométrique de $x$ et $y$. $h = \frac{2}{\frac{1}{x} + \frac{1}{y}}$ et $g = \sqrt{xy}$. $h \leq g \Leftrightarrow 2 \leq \sqrt{xy} \left(\frac{1}{x} + \frac{1}{y}\right) = \sqrt{\frac{y}{x}} + \sqrt{\frac{x}{y}}$. Posons $t = \sqrt{\frac{y}{x}}$. $t \geq 1$. On veut montrer $t + \frac{1}{t} \geq 2$. Vrai car $t + \frac{1}{t} - 2 = \frac{(t-1)^2}{t} \geq 0$. $$h \leq g$$

En résumé : $$x \leq h \leq g \leq m \leq y$$

Remarque : l'inégalité $g \leq m$ est équivalente à $\frac{x+y}{2} \geq \sqrt{xy}$, qui est un cas particulier de l'inégalité arithmético-géométrique.

Correction de l'exercice 2

Démonstration par récurrence sur $n$.

Initialisation ($n=0$ ou $n=1$): $(1+a)^1 = 1+a$, $1+1a = 1+a$. Vrai.

Hérédité: Supposons $(1+a)^n \geq 1+na$. $$(1+a)^{n+1} = (1+a)^n (1+a) \geq (1+na)(1+a)$$ $$= 1 + na + a + na^2 = 1 + (n+1)a + na^2$$ Puisque $a > 0$, $na^2 \geq 0$. $$(1+a)^{n+1} \geq 1 + (n+1)a$$ La propriété est héréditaire. Conclusion : $\forall a \in \mathbb{R}^+, \forall n \in \mathbb{N}, (1 + a)^n \geq 1+na$.

Correction de l'exercice 3

Pour $n \in \mathbb{N}^*$, par la formule du binôme : $$\left(1+\frac{1}{n}\right)^n = \sum_{k=0}^n \binom{n}{k} \frac{1}{n^k} = \sum_{k=0}^n u_k$$ où $u_k = \binom{n}{k} \frac{1}{n^k}$. Pour $k \in \{1, \dots, n-1\}$, le rapport $v_k = \frac{u_{k+1}}{u_k}$ vaut : $$v_k = \frac{\binom{n}{k+1} \frac{1}{n^{k+1}}}{\binom{n}{k} \frac{1}{n^k}} = \frac{n-k}{k+1} \frac{1}{n} = \frac{1}{k+1} \left(1 - \frac{k}{n}\right)$$ Puisque $k \geq 1$, $1 - \frac{k}{n} < 1$. Donc $v_k < \frac{1}{k+1}$.

Ensuite, on majore $u_k$ par récurrence : $u_k = u_{k-1} v_{k-1} < u_{k-1} \frac{1}{k}$. $$u_k < u_{k-1} \frac{1}{k} < u_{k-2} \frac{1}{k(k-1)} < \dots < u_1 \frac{1}{k! / 1!} = u_1 \frac{1}{(k-1)!}$$ $u_1 = \binom{n}{1} \frac{1}{n} = 1$. D'où $u_k < \frac{1}{k!}$.

En tenant compte de $u_0 = 1$ : $$\left(1+\frac{1}{n}\right)^n = \sum_{k=0}^n u_k = u_0 + \sum_{k=1}^n u_k$$ $$u_0 = 1$$ $$u_k = u_0 \cdot v_0 \cdot v_1 \dots v_{k-1} = 1 \cdot \frac{n}{1n} \cdot \frac{n-1}{2n} \cdot \frac{n-2}{3n} \dots$$ $$u_k = \frac{n(n-1)\dots(n-k+1)}{k!} \frac{1}{n^k} = \frac{1}{k!} \left(1\right)\left(1-\frac{1}{n}\right)\dots\left(1-\frac{k-1}{n}\right) < \frac{1}{k!}$$ $$\left(1+\frac{1}{n}\right)^n < \sum_{k=0}^n \frac{1}{k!} < \sum_{k=0}^\infty \frac{1}{k!} = e$$ Pour montrer $\left(1+\frac{1}{n}\right)^n < 3$, on utilise la majoration $k! \geq 2^{k-1}$ pour $k \geq 2$. $$\sum_{k=0}^n \frac{1}{k!} = 1 + 1 + \frac{1}{2!} + \dots + \frac{1}{n!} \leq 1 + 1 + \sum_{k=2}^n \frac{1}{2^{k-1}}$$ $$= 2 + \sum_{j=1}^{n-1} \frac{1}{2^j} = 2 + \frac{1/2(1-1/2^{n-1})}{1-1/2} = 2 + 1 - \frac{1}{2^{n-1}} = 3 - \frac{1}{2^{n-1}} < 3$$

Correction de l'exercice 4

Soient $n \in \mathbb{N}^*$ et $a_1, a_2, \dots, a_n \in \mathbb{R}^+_*$. On cherche à montrer $\left(\sum_{i=1}^n a_i\right) \left(\sum_{j=1}^n \frac{1}{a_j}\right) \geq n^2$. En développant le produit, on obtient : $$\sum_{i=1}^n \sum_{j=1}^n \frac{a_i}{a_j} = \sum_{i=j} \frac{a_i}{a_i} + \sum_{i \neq j} \frac{a_i}{a_j} = n + \sum_{i \neq j} \frac{a_i}{a_j}$$ Regroupons les termes $\frac{a_i}{a_j}$ et $\frac{a_j}{a_i}$ (pour $i < j$) : $$n + \sum_{1 \leq i < j \leq n} \left(\frac{a_i}{a_j} + \frac{a_j}{a_i}\right)$$ Pour $x > 0$, $f(x) = x + \frac{1}{x} \geq 2$. Puisque $\frac{a_i}{a_j} > 0$, $\frac{a_i}{a_j} + \frac{a_j}{a_i} \geq 2$. Le nombre de paires $(i, j)$ avec $i < j$ est $\binom{n}{2} = \frac{n(n-1)}{2}$. $$\sum_{i=1}^n \sum_{j=1}^n \frac{a_i}{a_j} \geq n + \sum_{1 \leq i < j \leq n} 2 = n + 2 \frac{n(n-1)}{2} = n + n^2 - n = n^2$$

Remarque : Ceci est un cas particulier de l'inégalité de Cauchy-Schwarz (voir Exercice 5).

Correction de l'exercice 5

On veut montrer $\sum_{k=1}^n a_k b_k \leq \sqrt{\sum_{k=1}^n a_k^2} \sqrt{\sum_{k=1}^n b_k^2}$. On a $\sum a_k b_k \leq \sum |a_k b_k|$ (trivial). On montre $\sum |a_k b_k| \leq \sqrt{\sum a_k^2} \sqrt{\sum b_k^2}$ en remplaçant $a_k$ et $b_k$ par $|a_k|$ et $|b_k|$. Considérons le polynôme $f(x) = \sum_{k=1}^n (a_k+b_k x)^2$. $\forall x \in \mathbb{R}, f(x) \geq 0$. $$f(x) = \sum_{k=1}^n (b_k^2 x^2 + 2a_k b_k x + a_k^2) = \left(\sum_{k=1}^n b_k^2\right) x^2 + 2\left(\sum_{k=1}^n a_k b_k\right) x + \left(\sum_{k=1}^n a_k^2\right)$$

1er cas: $\sum_{k=1}^n b_k^2 \neq 0$. $f(x)$ est un trinôme du second degré, toujours positif. Son discriminant réduit $\Delta'$ est négatif ou nul. $$\Delta' = \left(\sum_{k=1}^n a_k b_k\right)^2 - \left(\sum_{k=1}^n a_k^2\right) \left(\sum_{k=1}^n b_k^2\right) \leq 0$$ $$\left|\sum_{k=1}^n a_k b_k\right|^2 \leq \left(\sum_{k=1}^n a_k^2\right) \left(\sum_{k=1}^n b_k^2\right)$$ En prenant la racine carrée, on obtient l'inégalité de Cauchy-Schwarz.

2ème cas: $\sum_{k=1}^n b_k^2 = 0$. Alors $b_k = 0$ pour tout $k$. L'inégalité est $0 \leq 0$, triviale.

Retrouver l'inégalité de l'exercice 4: $\left(\sum_{i=1}^n a_i\right) \left(\sum_{j=1}^n \frac{1}{a_j}\right) \geq n^2$. Dans l'inégalité de Cauchy-Schwarz, posons $a'_k = \sqrt{a_k}$ et $b'_k = \sqrt{\frac{1}{a_k}}$. $$\sum_{k=1}^n \sqrt{a_k} \sqrt{\frac{1}{a_k}} \leq \sqrt{\sum_{k=1}^n a_k} \sqrt{\sum_{k=1}^n \frac{1}{a_k}}$$ $$\sum_{k=1}^n 1 = n$$ $$n^2 \leq \left(\sum_{k=1}^n a_k\right) \left(\sum_{k=1}^n \frac{1}{a_k}\right)$$

Correction de l'exercice 6

Soient $a, b, c \in \mathbb{R}^+$. On veut montrer que l'un des trois réels $A=a(1-b)$, $B=b(1-c)$, $C=c(1-a)$ est inférieur ou égal à $\frac{1}{4}$.

Si l'un des $a, b, c$ est strictement plus grand que $1$, par exemple $a > 1$, alors $C = c(1-a) < 0$. $C$ est donc $\leq 1/4$.

Supposons $a, b, c \in [0, 1]$. On a $A, B, C \geq 0$. Si $A > \frac{1}{4}$ et $B > \frac{1}{4}$ et $C > \frac{1}{4}$. Le produit $A B C = a(1-a) b(1-b) c(1-c)$. L'inégalité arithmético-géométrique donne $x(1-x) \leq \left(\frac{x+1-x}{2}\right)^2 = \frac{1}{4}$. $$ABC \leq \frac{1}{4} \cdot \frac{1}{4} \cdot \frac{1}{4} = \frac{1}{64}$$ D'autre part, si $A > 1/4, B > 1/4, C > 1/4$, alors $ABC > 1/64$. Contradiction. Donc l'une des hypothèses est fausse, i.e., au moins un des trois réels est $\leq \frac{1}{4}$.

Correction de l'exercice 7

  1. Soit $x \in \mathbb{R}$. $E(x) \leq x < E(x) + 1$. $E(x) + 1 \leq x+1 < E(x) + 2$. Puisque $E(x)+1$ est un entier, $E(x+1) = E(x) + 1$.
  2. Soient $x, y \in \mathbb{R}$. $E(x) \leq x$ et $E(y) \leq y$. $E(x) + E(y) \leq x+y$. $E(x) + E(y)$ est un entier inférieur ou égal à $x+y$. Puisque $E(x+y)$ est le plus grand entier inférieur ou égal à $x+y$, $$E(x) + E(y) \leq E(x+y)$$ (Le PDF utilise un $\leq$ strict, mais l'inégalité large est la bonne).
  3. Soient $x, y \in \mathbb{R}$. Posons $x = k + \alpha$ et $y = l + \beta$ avec $k, l \in \mathbb{Z}$ et $0 \leq \alpha, \beta < 1$. $E(x)+E(y)+E(x+y) = k+l+E(k+l+\alpha+\beta) = 2k+2l + E(\alpha+\beta)$. $E(2x)+E(2y) = E(2k+2\alpha)+E(2l+2\beta) = 2k+2l + E(2\alpha)+E(2\beta)$. On veut montrer $E(\alpha+\beta) \leq E(2\alpha) + E(2\beta)$. Si $0 \leq \alpha, \beta < 1$, alors $E(\alpha+\beta)$ vaut $0$ ou $1$. $E(2\alpha)$ vaut $0$ ou $1$. $E(2\beta)$ vaut $0$ ou $1$. Si $\alpha+\beta < 1$, $E(\alpha+\beta)=0$. $0 \leq E(2\alpha) + E(2\beta)$. Vrai. Si $\alpha+\beta \geq 1$, $E(\alpha+\beta)=1$. On a $2\alpha+2\beta \geq 2$. $E(2\alpha) + E(2\beta)$ peut être $0, 1$ ou $2$. Il est impossible que $E(2\alpha) + E(2\beta) = 0$ car $\alpha+\beta \geq 1 \Rightarrow 2\alpha+2\beta \geq 2$. Or $E(2\alpha)+E(2\beta) < 2\alpha + 2\beta$. Si $E(2\alpha)+E(2\beta)=0$, alors $2\alpha<1$ et $2\beta<1$, donc $\alpha+\beta<1$. Contradiction. Donc $E(2\alpha) + E(2\beta) \geq 1$. L'inégalité est vérifiée.

Correction de l'exercice 8

L'écriture en base 10 est $n = a_0 + 10a_1 + \dots + 10^p a_p$. $p$ est le plus grand entier tel que $10^p \leq n$. $$10^p \leq n < 10^{p+1}$$ En prenant le logarithme en base 10: $$p \leq \log_{10}(n) < p+1$$ $$p = E(\log_{10}(n))$$ $p+1$ est le nombre de chiffres de $n$.

Correction de l'exercice 9

Soit $x \in \mathbb{R}$ et $n \in \mathbb{N}^*$. Pour $k \in \{1, \dots, n\}$, on a $$kx - 1 < E(kx) \leq kx$$ En sommant pour $k=1$ à $n$: $$\sum_{k=1}^n (kx - 1) < \sum_{k=1}^n E(kx) \leq \sum_{k=1}^n kx$$ $$x \sum_{k=1}^n k - n < \sum_{k=1}^n E(kx) \leq x \sum_{k=1}^n k$$ $$\frac{n(n+1)}{2} x - n < \sum_{k=1}^n E(kx) \leq \frac{n(n+1)}{2} x$$ Divisons par $n^2$: $$\frac{n(n+1)x}{2n^2} - \frac{n}{n^2} < \frac{\sum_{k=1}^n E(kx)}{n^2} \leq \frac{n(n+1)x}{2n^2}$$ Quand $n \to +\infty$: $$\lim_{n \to +\infty} \left(\frac{n(n+1)x}{2n^2} - \frac{1}{n}\right) = \lim_{n \to +\infty} \left(\frac{x}{2} \left(1+\frac{1}{n}\right) - \frac{1}{n}\right) = \frac{x}{2}$$ $$\lim_{n \to +\infty} \frac{n(n+1)x}{2n^2} = \frac{x}{2}$$ Par le théorème des gendarmes, $$\lim_{n \to +\infty} \frac{E(x)+E(2x)+\dots+E(nx)}{n^2} = \frac{x}{2}$$

Correction de l'exercice 11

Soit $N = E(nx)$. $N$ est un entier. La division euclidienne de $N$ par $n$ donne $N = nq + r$, avec $q \in \mathbb{Z}$ et $r \in \{0, 1, \dots, n-1\}$. $q = E(N/n) = E(E(nx)/n) = E(x)$ (d'après Exercice 14). On a $N \leq nx < N+1$. $$nq + r \leq nx < nq + r + 1$$ $$q + \frac{r}{n} \leq x < q + \frac{r+1}{n}$$ On veut calculer $\sum_{k=0}^{n-1} E\left(x+\frac{k}{n}\right)$. Soit $k \in \{0, \dots, n-1\}$. $x + \frac{k}{n} = q + \frac{r}{n} + \epsilon$ avec $0 \leq \epsilon < \frac{1}{n}$. $$x + \frac{k}{n} = q + \frac{r+k}{n} + \epsilon$$ * Si $r+k < n$: $0 \leq \frac{r+k}{n} < 1$. $E\left(\frac{r+k}{n}\right) = 0$. $E\left(x+\frac{k}{n}\right) = q$. * Si $r+k \geq n$: $1 \leq \frac{r+k}{n} < 2$. $E\left(\frac{r+k}{n}\right) = 1$. $E\left(x+\frac{k}{n}\right) = q+1$. Le passage de $q$ à $q+1$ a lieu quand $r+k \geq n$, soit $k \geq n-r$. Le nombre de termes égaux à $q$ est $n-r$. Le nombre de termes égaux à $q+1$ est $n - (n-r) = r$. $$\sum_{k=0}^{n-1} E\left(x+\frac{k}{n}\right) = (n-r)q + r(q+1) = nq - rq + rq + r = nq + r$$ Puisque $nq+r = N = E(nx)$, l'identité est démontrée.

Correction de l'exercice 16

Montrer $\sqrt{n} < \sqrt[n]{n!}$. Équivalent à $n^{n/2} < n!$, soit $n^n < (n!)^2$.

$$(n!)^2 = \prod_{k=1}^n k \cdot \prod_{k=1}^n (n-k+1) = \prod_{k=1}^n k(n-k+1)$$ Il suffit de montrer que pour $k \in \{1, \dots, n\}$, $k(n-k+1) > n$. $k(n-k+1) = kn - k^2 + k$. On veut $kn - k^2 + k > n$. $n(k-1) + k(1-k) > 0 \Leftrightarrow (k-1)(n-k) > 0$. Vrai pour $k \in \{2, 3, \dots, n-1\}$. Pour $k=1$ et $k=n$, on a $(k-1)(n-k) = 0$. Si $n \geq 3$, il y a au moins un terme strictement plus grand que $n$. $$n!^2 = n \cdot \prod_{k=2}^{n-1} k(n-k+1) \cdot n$$ Puisque les termes intermédiaires sont $> n$, $n!^2 > n^n$. D'où $\sqrt{n} < \sqrt[n]{n!}$ pour $n \geq 3$.

Correction de l'exercice 18

Montrons par récurrence que : $\forall n \in \mathbb{N}, \forall x \in \mathbb{R}, |\sin(nx)| \leq n|\sin x|$.

Initialisation: $n=0$, $|\sin(0x)| = 0 \leq 0|\sin x|$. Vrai.

Hérédité: Supposons $|\sin(nx)| \leq n|\sin x|$ pour un certain $n \geq 0$. $$|\sin((n+1)x)| = |\sin(nx)\cos x + \cos(nx)\sin x|$$ $$\leq |\sin(nx)| |\cos x| + |\cos(nx)| |\sin x|$$ $$\leq |\sin(nx)| + |\sin x| \quad (\text{car } |\cos x| \leq 1, |\cos(nx)| \leq 1)$$ Par hypothèse de récurrence : $$\leq n|\sin x| + |\sin x| = (n+1)|\sin x|$$ La propriété est héréditaire. Conclusion : $\forall n \in \mathbb{N}, \forall x \in \mathbb{R}, |\sin(nx)| \leq n|\sin x|$.
