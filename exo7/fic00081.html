Exercice 1 (*IT)

Résoudre dans $\mathbb{R}$ puis dans $[0,2\pi]$ les équations suivantes :

  1. $\sin x = 0$
  2. $\sin x = 1$
  3. $\sin x = -1$
  4. $\cos x = 1$
  5. $\cos x = -1$
  6. $\cos x = 0$
  7. $\tan x = 0$
  8. $\tan x = 1$

Exercice 2 (*IT)

Résoudre dans $\mathbb{R}$ puis dans $[0,2\pi]$ les équations suivantes :

  1. $\sin x = \frac{1}{2}$
  2. $\sin x = -\frac{1}{\sqrt{2}}$
  3. $\tan x = -1$
  4. $\tan x = \frac{1}{\sqrt{3}}$
  5. $\cos x = \frac{\sqrt{3}}{2}$
  6. $\cos x = -\frac{1}{\sqrt{2}}$
Correction ▼
[005064]

Exercice 3 (**IT)

Résoudre dans $\mathbb{R}$ puis dans $I$ les équations suivantes :

  1. $\sin(2x) = \frac{1}{2}$, $I = [0,2\pi]$
  2. $\sin(\frac{x}{2}) = -\frac{1}{\sqrt{2}}$, $I = [0,4\pi]$
  3. $\tan(5x) = 1$, $I = [0, \pi]$
  4. $\cos(2x) = \cos^2 x$, $I = [0,2\pi]$
  5. $2\cos^2 x - 3\cos x + 1 = 0$, $I = [0,2\pi]$
  6. $\cos(nx) = 0$ ($n \in \mathbb{N}^*$)
  7. $|\cos(nx)| = 1$
  8. $\sin(nx) = 0$
  9. $|\sin(nx)| = 1$
  10. $\sin x = \tan x$, $I = [0,2\pi]$
  11. $\sin(2x) + \sin x = 0$, $I = [0,2\pi]$
  12. $12\cos^2 x - 8\sin^2 x = 2$, $I = [-\pi, \pi]$

Corrections

Correction de l'exercice 1

  1. $\sin x = 0 \iff x \in \pi\mathbb{Z}$. Dans $[0,2\pi]$, solutions : $\{0, \pi, 2\pi\}$.
  2. $\sin x = 1 \iff x \in \frac{\pi}{2} + 2\pi\mathbb{Z}$. Dans $[0,2\pi]$, solution : $\{\frac{\pi}{2}\}$.
  3. $\sin x = -1 \iff x \in -\frac{\pi}{2} + 2\pi\mathbb{Z}$. Dans $[0,2\pi]$, solution : $\{\frac{3\pi}{2}\}$.
  4. $\cos x = 1 \iff x \in 2\pi\mathbb{Z}$. Dans $[0,2\pi]$, solutions : $\{0, 2\pi\}$.
  5. $\cos x = -1 \iff x \in \pi + 2\pi\mathbb{Z}$. Dans $[0,2\pi]$, solution : $\{\pi\}$.
  6. $\cos x = 0 \iff x \in \frac{\pi}{2} + \pi\mathbb{Z}$. Dans $[0,2\pi]$, solutions : $\{\frac{\pi}{2}, \frac{3\pi}{2}\}$.
  7. $\tan x = 0 \iff x \in \pi\mathbb{Z}$. Dans $[0,2\pi]$, solutions : $\{0, \pi, 2\pi\}$.
  8. $\tan x = 1 \iff x \in \frac{\pi}{4} + \pi\mathbb{Z}$. Dans $[0,2\pi]$, solutions : $\{\frac{\pi}{4}, \frac{5\pi}{4}\}$.

Correction de l'exercice 2

  1. $\sin x = \frac{1}{2} \iff x \in (\frac{\pi}{6} + 2\pi\mathbb{Z}) \cup (\frac{5\pi}{6} + 2\pi\mathbb{Z})$. Dans $[0,2\pi]$, solutions : $\{\frac{\pi}{6}, \frac{5\pi}{6}\}$.
  2. $\sin x = -\frac{1}{\sqrt{2}} \iff x \in (-\frac{\pi}{4} + 2\pi\mathbb{Z}) \cup (-\frac{3\pi}{4} + 2\pi\mathbb{Z})$. Dans $[0,2\pi]$, solutions : $\{\frac{5\pi}{4}, \frac{7\pi}{4}\}$.
  3. $\tan x = -1 \iff x \in -\frac{\pi}{4} + \pi\mathbb{Z}$. Dans $[0, \pi]$, solution : $\{\frac{3\pi}{4}\}$.
  4. $\tan x = \frac{1}{\sqrt{3}} \iff x \in \frac{\pi}{6} + \pi\mathbb{Z}$. Dans $[0, \pi]$, solution : $\{\frac{\pi}{6}\}$.
  5. $\cos x = \frac{\sqrt{3}}{2} \iff x \in (-\frac{\pi}{6} + 2\pi\mathbb{Z}) \cup (\frac{\pi}{6} + 2\pi\mathbb{Z})$. Dans $[0,2\pi]$, solutions : $\{\frac{\pi}{6}, \frac{11\pi}{6}\}$.
  6. $\cos x = -\frac{1}{\sqrt{2}} \iff x \in (-\frac{3\pi}{4} + 2\pi\mathbb{Z}) \cup (\frac{3\pi}{4} + 2\pi\mathbb{Z})$. Dans $[0,2\pi]$, solutions : $\{\frac{3\pi}{4}, \frac{5\pi}{4}\}$.

Correction de l'exercice 3

  1. $\sin(2x) = \frac{1}{2} \iff 2x \in (\frac{\pi}{6} + 2\pi\mathbb{Z}) \cup (\frac{5\pi}{6} + 2\pi\mathbb{Z}) \iff x \in (\frac{\pi}{12} + \pi\mathbb{Z}) \cup (\frac{5\pi}{12} + \pi\mathbb{Z})$. Dans $[0,2\pi]$, solutions : $\{\frac{\pi}{12}, \frac{5\pi}{12}, \frac{13\pi}{12}, \frac{17\pi}{12}\}$.
  2. $\sin(\frac{x}{2}) = -\frac{1}{\sqrt{2}} \iff \frac{x}{2} \in (-\frac{\pi}{4} + 2\pi\mathbb{Z}) \cup (-\frac{3\pi}{4} + 2\pi\mathbb{Z}) \iff x \in (-\frac{\pi}{2} + 4\pi\mathbb{Z}) \cup (-\frac{3\pi}{2} + 4\pi\mathbb{Z})$. Dans $[0,4\pi]$, solutions : $\{\frac{5\pi}{2}, \frac{7\pi}{2}\}$.
  3. $\tan(5x) = 1 \iff 5x \in \frac{\pi}{4} + \pi\mathbb{Z} \iff x \in \frac{\pi}{20} + \frac{\pi}{5}\mathbb{Z}$. Dans $[0,\pi]$, solutions : $\{\frac{\pi}{20}, \frac{5\pi}{20}, \frac{9\pi}{20}, \frac{13\pi}{20}, \frac{17\pi}{20}\}$.
  4. $\cos(2x) = \cos^2 x \iff \cos(2x) = \frac{1+\cos(2x)}{2} \iff \cos(2x) = 1 \iff 2x \in 2\pi\mathbb{Z} \iff x \in \pi\mathbb{Z}$. Dans $[0,2\pi]$, solutions : $\{0, \pi, 2\pi\}$.
  5. $2\cos^2 x - 3\cos x + 1 = 0 \iff (2\cos x - 1)(\cos x - 1) = 0 \iff \cos x = \frac{1}{2}$ ou $\cos x=1$. Dans $[0,2\pi]$, solutions : $\{0, \frac{\pi}{3}, \frac{5\pi}{3}, 2\pi\}$.
  6. $\cos(nx) = 0 \iff nx \in \frac{\pi}{2} + \pi\mathbb{Z} \iff x \in \frac{\pi}{2n} + \frac{\pi}{n}\mathbb{Z}$.
  7. $|\cos(nx)|=1 \iff nx \in \pi\mathbb{Z} \iff x \in \frac{\pi}{n}\mathbb{Z}$.
  8. $\sin(nx)=0 \iff nx \in \pi\mathbb{Z} \iff x \in \frac{\pi}{n}\mathbb{Z}$.
  9. $|\sin(nx)|=1 \iff nx \in \frac{\pi}{2} + \pi\mathbb{Z} \iff x \in \frac{\pi}{2n} + \frac{\pi}{n}\mathbb{Z}$.
  10. $\sin x = \tan x \iff \sin x - \frac{\sin x}{\cos x}=0 \iff \sin x (1-\frac{1}{\cos x}) = 0 \iff \sin x = 0$ ou $\cos x=1$. C'est équivalent à $x \in \pi\mathbb{Z}$. Dans $[0,2\pi]$, solutions : $\{0, \pi, 2\pi\}$.
  11. $\sin(2x)+\sin x=0 \iff 2\sin x \cos x + \sin x = 0 \iff \sin x (2\cos x+1)=0 \iff \sin x=0$ ou $\cos x = -\frac{1}{2}$. Solutions dans $[0,2\pi]$ : $\{0, \pi, 2\pi, \frac{2\pi}{3}, \frac{4\pi}{3}\}$.
  12. $12\cos^2 x - 8\sin^2 x = 2 \iff 12\cos^2 x - 8(1-\cos^2 x)=2 \iff 20\cos^2 x = 10 \iff \cos^2 x = \frac{1}{2} \iff \cos x = \pm\frac{1}{\sqrt{2}}$. Dans $[-\pi,\pi]$, solutions : $\{-\frac{3\pi}{4}, -\frac{\pi}{4}, \frac{\pi}{4}, \frac{3\pi}{4}\}$.
