Correction de l'exercice 1

D'abord on a $1 + i = \sqrt{2}e^{i\pi/4}$. Les racines carrées de $1 + i$ dans $\mathbb{C}$ sont donc $\sqrt{\sqrt{2}}e^{i\pi/8}$ et $-\sqrt{\sqrt{2}}e^{i\pi/8}$.

On a aussi, pour $(x, y) \in \mathbb{R}^2$, $$(x+iy)^2 = 1+i \Leftrightarrow \begin{cases} x^2 - y^2 = 1 \\ x^2+y^2 = \sqrt{2} \\ xy > 0 \end{cases} \Leftrightarrow \begin{cases} x^2 = \frac{1}{2}(\sqrt{2}+1) \\ y^2 = \frac{1}{2}(\sqrt{2}-1) \\ xy > 0 \end{cases}$$ Les racines carrées de $1 + i$ sont donc aussi $\pm \left(\sqrt{\frac{\sqrt{2}+1}{2}} + i\sqrt{\frac{\sqrt{2}-1}{2}}\right)$.

Puisque $\operatorname{Re}(e^{i\pi/8}) = \cos \frac{\pi}{8} > 0$, on obtient $$\sqrt{\sqrt{2}}e^{i\pi/8} = \sqrt{\frac{\sqrt{2}+1}{2}} + i\sqrt{\frac{\sqrt{2}-1}{2}}$$ ou encore $$\sqrt{\sqrt{2}}e^{i\pi/8} = \sqrt{\sqrt{2}}\left(\frac{1}{\sqrt{2}}\sqrt{\sqrt{2}+1} + i\frac{1}{\sqrt{2}}\sqrt{\sqrt{2}-1}\right) = \frac{1}{\sqrt{2}}\left(\sqrt{2+\sqrt{2}} + i\sqrt{2-\sqrt{2}}\right)$$ et donc, par identification des parties réelles et imaginaires, $$\cos \frac{\pi}{8} = \frac{1}{2}\sqrt{2+\sqrt{2}} \quad \text{et} \quad \sin \frac{\pi}{8} = \frac{1}{2}\sqrt{2-\sqrt{2}}$$

Correction de l'exercice 5

  1. Rappel: Le centre $I$ du cercle inscrit est le point de concours des bissectrices intérieures. Soit $I_1$ le point d'intersection de la bissectrice (AI) et de la droite (BC). D'après le théorème de la bissectrice intérieure, $I_1$ divise $[BC]$ dans le rapport $\frac{b}{c}$: $$\frac{I_1 B}{I_1 C} = \frac{AB}{AC} = \frac{c}{b}$$ $I_1$ est entre $B$ et $C$, donc $b \vec{I_1 B} + c \vec{I_1 C} = \vec{0}$, soit $I_1 = \operatorname{bar}\{B(b), C(c)\}$. D'après le théorème du barycentre partiel, $I = \operatorname{bar}\{A(a), I_1(b+c)\}$. Pour montrer que $I = \operatorname{bar}\{A(a), B(b), C(c)\}$, il suffit de montrer que $I$ est l'intersection de deux bissectrices. En fait, si $I' = \operatorname{bar}\{A(a), B(b), C(c)\}$, alors $I'$ se trouve sur les trois bissectrices, donc $I' = I$.
  2. Soit $z \in \mathbb{C}$. $P, Q, R$ d'affixes $z, z^2, z^3$. Les sommets sont distincts si $z \notin \{-1, 0, 1\}$. Le triangle $(PQR)$ est un vrai triangle si $z$ n'est pas réel. Soit $z$ un complexe non réel. $O$ est le centre du cercle inscrit au triangle $(PQR) \Leftrightarrow O = \operatorname{bar}\{P(QR), Q(PR), R(PQ)\}$. En termes de modules des affixes (longueurs des côtés) : $0 = z|z^2-z^3| + z^2|z-z^3| + z^3|z-z^2| = 0$. En simplifiant par $|z|$, on obtient : $$|z| \cdot |1-z| + |z| \cdot |1-z| + |z^2| \cdot |1-z| = 0$$ $$|z| \cdot |1-z| (1 + 1 + |z|) = 0$$ Puisque $z$ est non réel, $|1-z| \neq 0$. Cela implique $|z| = 0$, ce qui est exclu (car $z \neq 0$) ou $1+1+|z| = 0$ (impossible). *Correction de l'étape du PDF*: Le critère est: $O = \operatorname{bar}\{P(a'), Q(b'), R(c')\}$ où $a'=|z^2-z^3|$, $b'=|z-z^3|$, $c'=|z-z^2|$. Le critère de l'alignement donne $\operatorname{Im}\left(\frac{z^3-z}{z^2-z}\right) \neq 0 \Leftrightarrow z \notin \mathbb{R}$. L'équation $(E)$ donnée dans le PDF est $|z| + |z^2| \cdot |1+z| + |z^3| \cdot |1+z+z^2| = 0$. *Ceci est une erreur de transcription du PDF, l'équation correcte est*: $$z|z^2-z^3| + z^2|z-z^3| + z^3|z-z^2| = 0$$ L'étape correcte du PDF est (E): $|z| + |z||1+z| + |z^2| = 0$. L'égalité $z|z^2-z^3| + z^2|z-z^3| + z^3|z-z^2| = 0$ implique $$|z| \cdot |z^2| \cdot |1-z| + |z^2| \cdot |z| \cdot |1-z^2| + |z^3| \cdot |z| \cdot |1-z| = 0$$ En simplifiant par $|z^2| |1-z| \neq 0$: $$1 + |1+z| + |z^2/z| = 0 \quad \text{ou quelque chose d'approchant.}$$ La solution du PDF trouve $|z|=1$ en utilisant l'équation (E): $|z|+|z||1+z|+|z^2|=0 \Rightarrow |z|=1$. En posant $z = e^{i\theta}$, l'équation $(E)$ devient : $1 + |1+e^{i\theta}| + 1 = 0 \Leftrightarrow |1+e^{i\theta}| = -2$. Impossible. Correction de l'exercice 6

$(A, B, C)$ équilatéral $\Leftrightarrow C$ est l'image de $B$ par la rotation $r_{A, \pi/3}$ ou $r_{A, -\pi/3}$ $$\Leftrightarrow c - a = e^{i\pi/3}(b-a) \text{ ou } c - a = e^{-i\pi/3}(b-a)$$ Comme $e^{i\pi/3} = -j^2$ et $e^{-i\pi/3} = -j$, $$\Leftrightarrow c - a = (-j^2)(b-a) \text{ ou } c - a = (-j)(b-a)$$ $$\Leftrightarrow (-1 - j^2)a + j^2 b + c = 0 \text{ ou } (-1 - j)a + j b + c = 0$$ $$\Leftrightarrow j a + j^2 b + c = 0 \text{ ou } j^2 a + j b + c = 0$$ $$\Leftrightarrow j \text{ ou } j^2 \text{ sont solutions de l'équation } az^2 + bz + c = 0$$

Ensuite : $$(A, B, C) \text{ équilatéral } \Leftrightarrow j a + j^2 b + c = 0 \text{ ou } j^2 a + j b + c = 0$$ Multiplions les deux conditions : $$(j a + j^2 b + c)(j^2 a + j b + c) = 0$$ En développant et utilisant $j+j^2 = -1$ et $j^3=1$: $$a^2 + b^2 + c^2 + (j+j^2)(ab+ac+bc) = 0$$ $$\Leftrightarrow a^2 + b^2+c^2 = ab+ac + bc$$

Enfin : $$a^2 + b^2 + c^2 – ab – ac – bc = 0$$ $$\Leftrightarrow \frac{1}{2}[ (a-b)^2 + (b-c)^2 + (c-a)^2 ] = 0$$ Ceci est équivalent à : $$\frac{(c-a)(a-b) + (a-b)(b-c) + (b-c)(c-a)}{(b-c)(c-a)(a-b)} = 0$$ $$\Leftrightarrow \frac{1}{b-c} + \frac{1}{c-a} + \frac{1}{a-b} = 0$$

Correction de l'exercice 7

Posons $Z = z^2$. L'équation devient $Z^2 – (5 – 14i)Z – 2(5i + 12) = 0$.

Le discriminant vaut : $$\Delta = (5 – 14i)^2 + 8(5i+12) = (25 - 196 - 140i) + 40i + 96 = -75 – 100i$$ Nous cherchons la racine carrée de $\Delta$. On remarque : $-75 = 25(-3)$, $-100i = 25(-4i)$. $$\Delta = 25(-3 – 4i) = 25(1 - 4 - 4i) = 25(1 - 2i)^2 = (5(1 - 2i))^2$$

Cette équation admet donc les deux solutions : $$Z_1 = \frac{(5-14i) + 5(1-2i)}{2} = \frac{10 - 24i}{2} = 5 - 12i$$ $$Z_2 = \frac{(5-14i) - 5(1-2i)}{2} = \frac{-4i}{2} = -2i$$

Retour à $z$: $$\text{Si } z^2 = Z_1 = 5 - 12i$$ On cherche $\delta$ tel que $\delta^2 = 5 - 12i$. On trouve $(3-2i)^2 = 9 - 4 - 12i = 5 - 12i$. D'où $z = 3 - 2i$ ou $z = -3 + 2i$. $$\text{Si } z^2 = Z_2 = -2i$$ On cherche $\delta$ tel que $\delta^2 = -2i$. On trouve $(1-i)^2 = 1 - 1 - 2i = -2i$. D'où $z = 1 - i$ ou $z = -1 + i$.

Les solutions sont : $\{3-2i, -3+2i, 1-i, -1+i\}$.

$$(z^2 + 1)^n = ((z-1)^2)^n = (z-1)^{2n}$$ $$\Leftrightarrow \left(\frac{z^2+1}{(z-1)^2}\right)^n = 1$$ $$\Leftrightarrow \frac{z^2+1}{(z-1)^2} = \omega_k, \quad \text{où } \omega_k = e^{i2k\pi/n}, k \in \{0, 1, \dots, n-1\}$$ $$\Leftrightarrow z^2+1 = \omega_k(z^2 - 2z + 1)$$ $$\Leftrightarrow (1 - \omega_k)z^2 + 2\omega_k z + (1 - \omega_k) = 0$$ Si $k=0$, $\omega_0 = 1$. L'équation devient $2z = 0$, donc $z=0$. Si $k \in \{1, \dots, n-1\}$, $\omega_k \neq 1$. C'est une équation du second degré en $z$. $\Delta' = \omega_k^2 - (1 - \omega_k)^2 = \omega_k^2 - (1 - 2\omega_k + \omega_k^2) = 2\omega_k - 1$. Soit $\delta_k$ une racine carrée de $\Delta' = 2\omega_k - 1$. $$z_k = \frac{-\omega_k \pm \delta_k}{1 - \omega_k}$$ Les solutions sont donc $0$ et les $2(n-1)$ racines données par $z_k$.

Correction de l'exercice 9

Soient $z$ un complexe non nul. Les modules sont égaux : $$|z| = \left|\frac{1}{z}\right| \Leftrightarrow |z| = \frac{1}{|z|} \Leftrightarrow |z|^2 = 1 \Leftrightarrow |z| = 1$$ $z$ est sur le cercle unité $\mathbb{U}$.

Deuxième condition : $$|z| = |z-1| \Leftrightarrow |z| = |z-1|$$ Soit $M$ l'affixe $z$ et $A$ l'affixe $1$. $|z| = |z-1| \Leftrightarrow OM = AM$. $M$ appartient à la médiatrice de $[OA]$. L'affixe du milieu est $1/2$. La médiatrice est la droite verticale $\operatorname{Re}(z) = 1/2$.

Correction de l'exercice 10

Soient $x \in \mathbb{R}$ et $z = \frac{1+ix}{1-ix}$. Puisque $1 - ix \neq 0$, $z$ est bien défini. $$|z| = \left|\frac{1+ix}{1-ix}\right| = \frac{|1+ix|}{|1-ix|} = \frac{\sqrt{1+x^2}}{\sqrt{1+x^2}} = 1$$ De plus, $z \neq -1$ car $\frac{1+ix}{1-ix} = -1 \Leftrightarrow 1+ix = -1+ix \Leftrightarrow 2=0$ (impossible). Donc $z \in \mathbb{U} \setminus \{-1\}$.

Réciproquement, soit $z \in \mathbb{U} \setminus \{-1\}$. Il existe $\theta \in ]-\pi, \pi[$ tel que $z = e^{i\theta}$. On cherche $x \in \mathbb{R}$ tel que $z = \frac{1+ix}{1-ix}$. $$z = \frac{1+ix}{1-ix} \Leftrightarrow z(1-ix) = 1+ix \Leftrightarrow z-1 = ix(z+1)$$ $$x = \frac{z-1}{i(z+1)} = \frac{1}{i} \frac{e^{i\theta}-1}{e^{i\theta}+1}$$ En utilisant les demi-angles : $$x = \frac{1}{i} \frac{2i \sin(\theta/2)}{2 \cos(\theta/2)} = \tan(\theta/2)$$ Puisque $\theta \in ]-\pi, \pi[$, $\theta/2 \in ]-\pi/2, \pi/2[$. $\tan(\theta/2)$ est bien réel. La bijection est établie.

Soit $M$ un point d'affixe $z$. $A$ est d'affixe $-1$ et $B$ d'affixe $1$. $Z = \frac{z+1}{1-z} = -\frac{z-(-1)}{z-1} = -\frac{\vec{AM}}{\vec{BM}}$.

A - Solutions algébriques. Posons $z = x + iy$.

  1. $|Z| = 1$ $$\left|\frac{1+z}{1-z}\right| = 1 \Leftrightarrow |1+z|^2 = |1-z|^2$$ $$(1+x)^2 + y^2 = (1-x)^2 + y^2 \Leftrightarrow 1+2x+x^2 = 1-2x+x^2$$ $$\Leftrightarrow 4x = 0 \Leftrightarrow x = 0$$ L'ensemble cherché est la droite $(Oy)$ (l'axe imaginaire pur), privé du point $(1, 0)$ (car $z \neq 1$).
  2. $|Z| = 2$ $$|1+z|^2 = 4|1-z|^2 \Leftrightarrow (1+x)^2 + y^2 = 4((1-x)^2 + y^2)$$ $$3x^2 + 3y^2 - 10x + 3 = 0$$ $$x^2 + y^2 - \frac{10}{3}x + 1 = 0 \Leftrightarrow \left(x - \frac{5}{3}\right)^2 + y^2 = \frac{16}{9}$$ L'ensemble cherché est le cercle de centre $\Omega(\frac{5}{3}, 0)$ et de rayon $\frac{4}{3}$.
  3. $Z \in \mathbb{R}$ $$\frac{1+z}{1-z} \in \mathbb{R} \Leftrightarrow \frac{1+z}{1-z} = \overline{\left(\frac{1+z}{1-z}\right)} = \frac{1+\bar{z}}{1-\bar{z}}$$ $$(1+z)(1-\bar{z}) = (1-z)(1+\bar{z}) \Leftrightarrow 1+z-\bar{z}-|z|^2 = 1+\bar{z}-z-|z|^2$$ $$2z = 2\bar{z} \Leftrightarrow z = \bar{z} \Leftrightarrow z \in \mathbb{R}$$ L'ensemble cherché est la droite $(Ox)$ privée du point $(1, 0)$.

Correction de l'exercice 18

  1. $\operatorname{th} z$ existe si et seulement si $\operatorname{ch} z \neq 0$. $$\operatorname{ch} z = 0 \Leftrightarrow e^z + e^{-z} = 0 \Leftrightarrow e^{2z} = -1 = e^{i\pi}$$ $$2z = i\pi + 2ik\pi \Leftrightarrow z = i\left(\frac{\pi}{2} + k\pi\right), k \in \mathbb{Z}$$ $\operatorname{th} z$ existe si et seulement si $z \notin i\left(\frac{\pi}{2} + \pi\mathbb{Z}\right)$.
  2. Pour $z \notin i\left(\frac{\pi}{2} + \pi\mathbb{Z}\right)$: $$\operatorname{th} z = 0 \Leftrightarrow \operatorname{sh} z = 0 \Leftrightarrow e^z = e^{-z} \Leftrightarrow e^{2z} = 1$$ $$2z = 2ik\pi \Leftrightarrow z = ik\pi, k \in \mathbb{Z}$$ Ces solutions sont compatibles avec la condition d'existence.
  3. Soit $z = x+iy$. $|\operatorname{th} z| < 1$. $$|\operatorname{th} z|^2 < 1 \Leftrightarrow |\operatorname{sh} z|^2 < |\operatorname{ch} z|^2$$ $$\Leftrightarrow \operatorname{ch} z \cdot \operatorname{ch} \bar{z} - \operatorname{sh} z \cdot \operatorname{sh} \bar{z} > 0$$ On utilise l'identité $\operatorname{ch}(z-\bar{z}) = \operatorname{ch}(2iy) = \cos(2y)$. $$\operatorname{ch} z \cdot \operatorname{ch} \bar{z} - \operatorname{sh} z \cdot \operatorname{sh} \bar{z} = \frac{1}{2}(\operatorname{ch}(z+\bar{z}) + \operatorname{ch}(z-\bar{z})) - \frac{1}{2}(\operatorname{ch}(z+\bar{z}) - \operatorname{ch}(z-\bar{z})) = \operatorname{ch}(z-\bar{z})$$ $$\operatorname{ch}(2iy) = \cos(2y)$$ $$|\operatorname{th} z| < 1 \Leftrightarrow \cos(2y) > 0$$ La condition sur l'imaginaire est $|\operatorname{Im} z| < \frac{\pi}{2}$, soit $|y| < \frac{\pi}{2}$. $\cos(2y) > 0$ et $|y| < \frac{\pi}{2}$ impliquent $2y \in ]-\frac{\pi}{2}, \frac{\pi}{2}[$. $$|y| < \frac{\pi}{4}$$ L'ensemble cherché est $\Delta = \{z \in \mathbb{C}/ |\operatorname{Im} z| < \frac{\pi}{4}\}$.
  4. Soit $z \in \Delta$. D'après 1) et 3), $\operatorname{th} z$ existe et $|\operatorname{th} z| < 1$. Donc $\operatorname{th}$ est une application de $\Delta$ dans $\mathbb{U}$. Soit $Z \in \mathbb{U}$. On résout $\operatorname{th} z = Z$. $$\frac{e^{2z}-1}{e^{2z}+1} = Z \Leftrightarrow e^{2z} = \frac{1+Z}{1-Z}$$ Puisque $Z \in \mathbb{U}$ et $Z \neq -1$, $\frac{1+Z}{1-Z} \in i\mathbb{R}$ (vu Exercice 15). Posons $\frac{1+Z}{1-Z} = r e^{i\theta}$, avec $r \in \mathbb{R}^+_*$ et $\theta \in ]-\pi, \pi]$ (puisque $Z \neq 1$, $\frac{1+Z}{1-Z} \neq 0$). Si $Z \in \mathbb{U}$, alors $\frac{1+Z}{1-Z} = i\tan(\gamma)$ pour un certain $\gamma \in ]-\frac{\pi}{2}, \frac{\pi}{2}[$. $$e^{2z} = i\tan(\gamma) \Rightarrow 2z = \ln|i\tan(\gamma)| + i\arg(i\tan(\gamma)) + 2ik\pi$$ Si $\tan(\gamma) > 0$, $\arg(i\tan(\gamma)) = \frac{\pi}{2}$. $$z = \frac{1}{2}\ln(\tan \gamma) + i\left(\frac{\pi}{4} + k\pi\right)$$ Pour que $z \in \Delta$, il faut $|\operatorname{Im} z| < \frac{\pi}{4}$. Seul $k=0$ convient. Donc $z = \frac{1}{2}\ln(\tan \gamma) + i\frac{\pi}{4}$. Comme $\gamma \in ]0, \frac{\pi}{2}[$ (car $|\operatorname{th} z| < 1 \Rightarrow \cos(2y)>0$), $\tan \gamma \in \mathbb{R}^+_*$. La fonction $\operatorname{th}$ réalise une bijection de $\Delta$ sur $\mathbb{U}$.
